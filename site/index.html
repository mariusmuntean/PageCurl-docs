PageCurl.Maui

PageCurl.Maui adds page turns to .NET MAUI applications. Use it for images, live views or a two-page reader. Pages curl from an edge or pinned corner; buttons and gestures share the same completion event.

Motion preview

The 20-second Mac Catalyst recording shows a committed drag and snap-back, a spread turn, a live counter update, and switching scenes during a turn. Playback runs at normal speed. Download the preview.

Choose a control

Control Use it for Content ownership
PageTurnView Images you already render You own the SKImage values
PageCurlView A live MAUI page The control owns captured textures
PageSpreadView Two-page navigation The control captures up to six views

Start with the quick start, then read the runtime rules before connecting a page model. The small reader example supplies a complete five-page recipe with navigation, capture retry and the odd last page.

Current release status

Version 0.1.0 is available on NuGet.org and targets .NET 10 and MAUI 10. Public APIs may change before 1.0. Use the platform matrix to distinguish build coverage from runtime and hardware validation. See the quick start for package installation and a working example.

The sample includes Single, Spread, Content and Backside scenes, a live counter, local video, anchor choices, reduced motion and page-turn commands.
