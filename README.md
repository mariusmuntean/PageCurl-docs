# PageCurl.Maui documentation

[Read the documentation](https://mariusmuntean.github.io/PageCurl-docs/).

This repository hosts the generated guides and public API reference. The source
repository currently requires access. Edit documentation in the source repository,
then run `tools/publish-docs.sh` there to rebuild and publish the validated site.

The Pages workflow deploys `site/`. This repository does not contain library source,
packages or historical validation logs. Documentation is available under the
[MIT license](LICENSE).
